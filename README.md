# awesome-open

> A curated index of valuable open-source projects

## Overview

**awesome-open** maintains a comprehensive index of high-quality open-source projects that inspire and contribute to the open-source ecosystem. We showcase projects that exemplify excellent open-source practices and innovation.

This index focuses on **open-source alternatives to popular commercial products**, making it easier for developers and organizations to find high-quality alternatives that offer privacy, transparency, and community-driven development.

## Contributing

We welcome contributions! If you'd like to add a project to this index, please:

1. **Requirements:**
   - Project must be open-source (MIT, Apache 2.0, GPL, or similar)
   - Should have 100+ stars or be a clear alternative to a commercial product
   - Include a meaningful description (50-100 words)
   - Verify the project is actively maintained

2. **Steps:**
   - Fork the repository
   - Create a feature branch (`feature/add-project-name`)
   - Add your project to the appropriate category with format:
     ```markdown
     | [owner/repo-name](https://github.com/owner/repo-name) | **stars** | Description | Language |
     ```
   - Submit a pull request with a clear description

3. **Format Example:**
   ```markdown
   | [vercel/ai](https://github.com/vercel/ai) | **31k** | AI Toolkit for TypeScript - build AI-powered applications | TypeScript |
   ```
